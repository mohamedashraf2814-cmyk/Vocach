# فوكاش — نظام إدارة التحويلات المالية ونقاط البيع ومخزون الإكسسوارات

نظام ويب عربي بالكامل (RTL) لإدارة:

- عمليات المحافظ الإلكترونية: فودافون كاش، إنستاباي، ماستركارد، ومحافظ أخرى
- الحسابات والخطوط مع الحدود اليومية والشهرية، وقواعد العمولة
- نقطة بيع (POS) لإكسسوارات الموبايل مع فواتير قابلة للطباعة
- المنتجات والتصنيفات وحركات المخزون والمشتريات
- العملاء، المصروفات، التقفيل اليومي، التقارير
- المستخدمون والأدوار والصلاحيات، سجل النشاط، الإشعارات، الإعدادات

> النظام **لا يحتوي على أي بيانات تجريبية**. قاعدة البيانات تبدأ فارغة تماماً، ولا توجد حسابات دخول افتراضية.
> النظام **يسجّل** العمليات المالية فقط ولا ينفّذ أي تحويل مالي فعلي عبر مقدمي الخدمة.

## المتطلبات

- Node.js **22.13 أو أحدث** (يستخدم قاعدة SQLite المدمجة في Node عبر `node:sqlite`)

## التشغيل

```bash
npm install

# وضع التطوير (الواجهة على http://localhost:5173 والخادم على 3001)
npm run dev

# وضع الإنتاج
npm run build
npm start          # يعمل على http://localhost:3001
```

عند فتح النظام لأول مرة ستظهر شاشة **«إعداد النظام لأول مرة»** لإنشاء حساب مدير النظام بنفسك.
بعدها يمكنك إضافة مستخدمين وأدوار بصلاحيات محددة من «المستخدمون والصلاحيات».

### النشر على Render (لينك عام)

المستودع فيه ملف `render.yaml` جاهز. من حسابك على Render اختار **New ← Blueprint** واختار هذا المستودع، أو افتح:
`https://render.com/deploy?repo=https://github.com/mohamedashraf2814-cmyk/Vocach`
سيتم إنشاء الخدمة مع قرص دائم لحفظ قاعدة البيانات والملفات (القرص يتطلب خطة Starter المدفوعة على Render).

### متغيرات البيئة (اختيارية)

| المتغير | الوصف | الافتراضي |
|---|---|---|
| `PORT` | منفذ الخادم | `3001` |
| `DATA_DIR` | مجلد قاعدة البيانات والملفات المرفوعة | `./data` |
| `DB_PATH` | مسار ملف قاعدة البيانات | `DATA_DIR/vocach.db` |
| `TRUST_PROXY` | فعّله عند التشغيل خلف Nginx أو بروكسي (مثال: `1`) | — |

مجلد `data/` مستثنى من Git. خذ نسخة احتياطية منه دورياً.

## البنية

```
server/            خادم Express + SQLite
  db.js            المخطط (المبالغ مخزنة بالقرش كأعداد صحيحة)
  auth.js          الجلسات (كوكي HttpOnly)، CSRF، كلمات المرور (scrypt)، الصلاحيات
  routes/          auth, admin (مستخدمون/أدوار/إعدادات/سجل), finance (حسابات/عمولات/تحويلات/عملاء),
                   inventory (منتجات/مخزون/مشتريات/مبيعات), operations (مصروفات/تقفيل/تقارير/إشعارات)
src/               واجهة React + TypeScript (Vite)
  lib/             عميل API، المصادقة، الأدوات، الثوابت
  components/      مكونات مشتركة (ui.tsx) والهيكل العام (Layout.tsx)
  pages/           صفحات النظام
  styles.css       رموز التصميم والأنماط (RTL، متجاوب، طباعة)
```

## ملاحظات على منطق العمل

- **العمولة**: تُحسب في الخادم من «قواعد العمولة» المفعّلة (الأكثر تحديداً حسب الخدمة ونوع العملية ونطاق المبلغ). إن لم توجد قاعدة تكون صفراً، ويمكن إدخالها يدوياً عند التسجيل (ويُسجل ذلك في سجل النشاط).
- **الحدود**: الاستخدام اليومي/الشهري = مجموع مبالغ العمليات غير الملغاة على الحساب. يمكن منع تجاوز الحد من الإعدادات.
- **المخزون**: لا تتغير الكميات إلا عبر البيع أو إلغاء الفاتورة أو المشتريات أو حركات المخزون، وكل تغيير يُسجل كحركة.
- **التقفيل اليومي**: الوارد = المبيعات النقدية + عمليات الإرسال (المبلغ + العمولة) + عمولات الاستلام. المنصرف = مبالغ الاستلام/السحب + المصروفات + المشتريات (اختياري). يُعاد الحساب في الخادم لحظة الحفظ.
- **التصدير**: التقارير تُصدَّر بصيغة CSV متوافقة مع Excel، والطباعة/PDF عبر نافذة الطباعة في المتصفح.
